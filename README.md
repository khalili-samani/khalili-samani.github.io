# Personal Portfolio Website

This repository contains the source code for my personal portfolio website.

The website showcases my background, technical skills and portfolio projects in data analytics, machine learning, data engineering and statistical modelling.

## Website Sections

- **Home** – Introduction and overview of my expertise.
- **About** – Academic background, professional profile and technical skills.
- **Projects** – A selection of end-to-end analytics, machine learning and data engineering projects.
- **Contact** – Contact information and professional links.

## Technologies

- HTML5
- CSS3

## Purpose

The website serves as a central portfolio, providing an overview of my experience and links to my GitHub projects and professional profiles.
