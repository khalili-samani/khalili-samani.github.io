A selection of portfolio projects demonstrating practical work across data analytics, business intelligence, data engineering, machine learning and decision support. The projects cover data cleaning, SQL and dimensional modelling, Power BI and Excel reporting, automated data pipelines, financial analytics, time-series forecasting and reproducible analytical workflows using Australian and synthetic datasets.

Luxury Fashion Outlet Sales Analysis in Power BI

Built a five-page Power BI management report analysing sales, profitability, promotions, products, staff, customer segments, returns and customer contact-data capture for a synthetic luxury fashion outlet. The workflow cleaned 6,287 raw transaction rows in Power Query, retained 6,200 unique transactions, established a star-schema data model and created reusable DAX measures for commercial and operational KPIs.

The completed report recorded $2,368,788.63 in net sales, $917,028.73 in gross profit, a 38.71% gross margin, a $382.06 average order value and a 3.24% return rate. Category analysis showed womenswear generated the highest net sales, while accessories recorded the highest gross margin and outerwear the lowest. The dataset, staff, customers and operating scenario are entirely synthetic.

Technologies: Power BI Desktop, Power Query (M), DAX

Skills: Data cleaning, dimensional modelling, KPI design, DAX, dashboard development, reconciliation, business analysis, data visualisation, stakeholder reporting

Australian NEM Price Forecasting

Developed a Python-based forecasting workflow for estimating Australian National Electricity Market dispatch prices 30 minutes ahead using AEMO market data, available Bureau of Meteorology temperature observations and time-series feature engineering. The implemented pipeline covers data ingestion, MySQL storage, cleaning, region-specific lag and rolling features, chronological model validation and delivery through a Streamlit forecasting interface.

The persisted XGBoost model recorded a hold-out mean absolute error of $19.02/MWh, RMSE of $33.43/MWh and R² of 0.5085 using a chronological 70% training, 15% validation and 15% test split. The repository treats these as prototype evaluation results rather than evidence of production forecasting performance because the saved test artefact does not preserve all contextual information required for a complete benchmark.

Technologies: Python, MySQL, Pandas, SQLAlchemy, XGBoost, Streamlit

Skills: Time-series forecasting, data ingestion, ETL, feature engineering, leakage prevention, chronological validation, model evaluation, analytical application development

ASX Equity Intelligence Agent

Designed a structured equity-research workflow that collects Australian market data, forecasts next-session returns, calculates risk measures, applies deterministic recommendation rules and generates a daily Markdown market briefing. Five LangGraph nodes manage market data, forecasting, risk, strategy and report generation through a shared typed state, with Gemini used only after the numerical analysis and recommendation logic have been completed.

The supplied DuckDB database contains 2,630 equity OHLCV records across 10 ASX-listed securities. A verified run on 23 June 2026 processed all 10 watchlist tickers, generated 10 forecasts and 10 risk assessments, and produced one BUY, eight HOLD and one REDUCE recommendation. The verified execution demonstrates pipeline consistency, not forecast profitability or investment performance.

Technologies: Python, DuckDB, Pandas, NumPy, Scikit-learn, LangGraph, Gemini API

Skills: Financial time-series analysis, machine learning, feature engineering, risk analytics, workflow orchestration, deterministic decision logic, LLM-constrained reporting

Australian NEM Price and Demand Pipeline

Built a Python and MySQL analytics pipeline for downloading, cleaning, storing, aggregating and visualising wholesale electricity price and demand data from the Australian National Electricity Market. The workflow standardises AEMO monthly files, loads five-minute settlement records into a relational fact table, creates reusable SQL reporting views and generates charts directly from database queries.

The supplied March 2026 dataset contains 26,784 records across New South Wales, Queensland and Victoria, with 8,928 five-minute intervals per region. Victoria recorded the lowest average price but the highest interval-level price volatility and the highest frequency of negative-price intervals, demonstrating why monthly averages need to be interpreted alongside price dispersion and volatility.

Technologies: Python, Pandas, SQL, MySQL, SQLAlchemy, PyMySQL, Matplotlib

Skills: ETL development, data validation, relational modelling, SQL reporting, electricity-market analysis, pipeline orchestration, automated visualisation

Sector-Based Stock Market Analysis

Built a Python and MySQL analytics workflow comparing daily returns and price volatility across 12 selected US-listed companies in Technology, Finance, Energy and Healthcare. The pipeline cleans OHLCV files with Pandas, loads 9,024 price records into a dimensional MySQL model and uses SQL analytical views to calculate daily returns and company-level and sector-level metrics.

Across the supplied period from 1 March 2023 to 27 February 2026, Nvidia recorded both the highest average daily return and the highest daily volatility in the selected sample, while Johnson & Johnson recorded the lowest daily volatility. The analysis is descriptive and compares the selected securities rather than representing each sector or providing investment recommendations.

Technologies: Python, Pandas, SQL, MySQL, SQLAlchemy, Matplotlib

Skills: SQL analytics, dimensional modelling, window functions, return analysis, volatility analysis, financial data pipelines, reproducible visualisation

Australian Housing Data Quality Simulator

Developed a configurable Python program that generates synthetic Australian residential property-sale data containing deliberately introduced data-quality defects. The generator creates plausible property and transaction attributes before introducing missing values, inconsistent categories, malformed fields, invalid values, exact duplicates and near-duplicate listing records for downstream cleaning and ETL practice.

A verified example covering January 2021 to December 2023 for New South Wales, Queensland and Victoria produced 11,190 rows across 37 columns, including 128 fully duplicated rows and 360 rows with repeated listing identifiers. Because generation is stochastic, these figures describe the supplied example rather than guaranteed output from every run.

Technologies: Python, Pandas

Skills: Synthetic data generation, data-quality engineering, rule-based simulation, malformed-data handling, ETL test-data preparation, validation design, exploratory data analysis

Australian Emergency Department Demand and Waiting Time Analysis

Created an Excel-only healthcare analytics project using a realistic synthetic emergency department dataset to demonstrate data cleaning, validation, KPI design, formula-based analysis, charting and management dashboard development. The cleaned dataset contains 12,079 encounters from 12 fictional facilities across Australian states and territories, covering 1 January 2024 to 31 December 2025.

The analysis reported a 4.9% increase in presentation volume in 2025, an overall within-target rate of 44.7% and an admission rate of 29.0% in the synthetic scenario. Remote facilities recorded the lowest within-target performance by region type, while mental health presentations had an average emergency department length of stay of approximately 438 minutes. These findings are illustrative and must not be interpreted as real Australian health-service performance.

Technologies: Microsoft Excel

Skills: Excel data cleaning, structured references, XLOOKUP, INDEX/MATCH, SUMIFS, COUNTIFS, dynamic arrays, KPI design, dashboard development, healthcare analytics, data-quality validation

Australian Housing SQL Quality and Market Analytics Warehouse

Extended the Australian Housing Data Quality Simulator into a governed MySQL analytics warehouse that transforms intentionally unreliable synthetic property extracts into auditable analytical data products. The workflow preserves raw batch lineage, applies reusable standardisation rules, classifies duplicate and rejected records, uses deterministic survivorship logic and loads accepted canonical sale events into a dimensional warehouse.

The architecture includes raw and staging layers, a star schema, rejected-record auditing, reporting marts and SQL-based data-quality tests. Analytical SQL covers window functions, Australian financial-year logic, rolling metrics, cohort analysis, SCD Type 2 agent dimensions, reconciliation and performance optimisation. Results depend on the selected synthetic generator run, so the repository does not claim precomputed market findings.

Technologies: MySQL, SQL, Python, Docker

Skills: Analytics engineering, SQL data cleaning, dimensional modelling, duplicate survivorship, SCD Type 2 modelling, data-quality testing, reconciliation, analytical SQL, warehouse optimisation

Queensland Elective Surgery Capacity and Waitlist Recovery Optimiser

Developing a healthcare operations analytics system intended to support allocation of additional elective-surgery capacity across Queensland public facilities and specialties. The project frames capacity allocation as a constrained decision problem that must account for long waits, clinical urgency, operational limits, service coverage, regional access, equity and uncertainty rather than relying on throughput alone.

The implemented foundation currently includes typed configuration, validated YAML planning scenarios, structured logging, a Typer command-line interface, Queensland Open Data CKAN dataset discovery, deterministic resource identification, retry-aware retrieval, source validation, SHA-256 hashing, immutable raw-file storage, duplicate-content detection, lineage manifests and automated ingestion tests. Data-quality modelling, DuckDB analytics, OR-Tools optimisation, simulation, FastAPI and Streamlit components remain in development or planned and are not presented as completed results.

Implemented technologies: Python 3.12, Pydantic Settings, YAML, Typer, pytest

Planned analytical stack: DuckDB, OR-Tools, FastAPI, Streamlit

Skills: Healthcare analytics engineering, API data ingestion, configuration management, data lineage, reproducible pipelines, validation, automated testing, operations research design

Status: Active development
