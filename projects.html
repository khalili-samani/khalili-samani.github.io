Projects

A selection of end-to-end analytics projects demonstrating data engineering, SQL, machine learning, forecasting, dashboard development and AI-assisted analytical workflows.

Australian NEM Price Forecasting

Built an end-to-end analytics and machine learning platform to forecast Australian National Electricity Market dispatch prices 30 minutes ahead using electricity market and weather data. The project includes data ingestion, MySQL database design, feature engineering, XGBoost modelling and an interactive Streamlit dashboard.

Technologies: Python, SQL, MySQL, Pandas, XGBoost, Streamlit

Skills: Time-series forecasting, data engineering, feature engineering, model evaluation, dashboard development

ASX Equity Intelligence Agent

Developed a multi-agent AI system that automates ASX equity analysis by collecting market data, forecasting next-day returns, assessing portfolio risk, generating trading recommendations and producing structured market briefings. The system combines quantitative analytics, machine learning, risk metrics and LLM-based reporting.

Technologies: Python, DuckDB, Pandas, Scikit-learn, LangGraph, Gemini API

Skills: Financial analytics, risk analysis, machine learning, agent orchestration, AI-assisted reporting

Australian Energy Market Analysis Pipeline

Created an end-to-end ETL and analytics pipeline for Australian National Electricity Market data. The project collects, cleans, validates and loads wholesale electricity market data into MySQL, then generates SQL reporting views and automated visual reports for regional price, demand and volatility analysis.

Technologies: Python, SQL, MySQL, Pandas, SQLAlchemy, Matplotlib

Skills: ETL development, SQL reporting, database design, market analysis, automated visualisation

Sector-Based Stock Market Analysis

Designed a reusable financial analytics pipeline to analyse risk and return across major US companies in the Technology, Finance, Energy and Healthcare sectors. Historical stock data is cleaned, loaded into a MySQL data warehouse, transformed through SQL analytical views and visualised through automated reporting charts.

Technologies: Python, SQL, MySQL, Pandas, SQLAlchemy, Matplotlib

Skills: SQL analytics, data warehousing, return analysis, volatility analysis, financial reporting

Australian Housing Data Quality Simulator

Built a Python-based synthetic data generation tool that creates realistic, intentionally messy Australian residential property datasets for data cleaning, ETL, SQL, BI and machine learning practice. The simulator models housing market conditions from 2020 to 2025 and introduces common real-world data quality issues such as missing values, inconsistent formats, duplicates and outliers.

Technologies: Python, Pandas, NumPy, CSV

Skills: Synthetic data generation, data quality simulation, data modelling, ETL testing, analytics preparation
